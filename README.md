# Durak Tracker Overlay — 24 карты

Android APK с локальным ручным учётом карт и плавающим окном поверх других приложений.

## Функции
- Колода 24 карты: 9, 10, В, Д, К, Т четырёх мастей.
- Статусы: МОЯ, КОЛОДА, ПРОТИВНИК, ВЫШЛА.
- Локальное сохранение состояния.
- Плавающее окно со счётчиками, перемещение за заголовок и закрытие крестиком.

## Сборка APK
Загрузите содержимое ZIP в GitHub-репозиторий, откройте Actions и запустите workflow. Скачайте artifact `Durak-Tracker-Overlay-APK`.

## Ограничения
Приложение не подключается к серверу RSTGames, не перехватывает сетевой трафик, не модифицирует игровой клиент и не распознаёт закрытые карты соперника. Это локальный ручной счётчик. Для официальной интеграции нужно письменное разрешение разработчика и документированный API.
